# =============================================================================
# Oracle RAG Service - Dependencies
# =============================================================================
# This service implements Retrieval-Augmented Generation (RAG) for movie Q&A
# using subtitle transcripts as the knowledge base.
#
# Key Libraries:
#   - fastapi: Modern async web framework (consistent with movie-assistant-service)
#   - langchain: RAG chain orchestration, prompt templates, retriever abstraction
#   - chromadb: Vector database for storing/searching subtitle chunk embeddings
#   - sentence-transformers: Generate dense vector embeddings locally (no API costs)
#   - ollama: Python client for local LLM inference via Ollama server
#
# Pipeline: .srt → Parse → Chunk → Embed (sentence-transformers) → ChromaDB
# Inference: Query → Embed → Vector Search → Top-K Chunks → Ollama LLM → Answer
# =============================================================================
